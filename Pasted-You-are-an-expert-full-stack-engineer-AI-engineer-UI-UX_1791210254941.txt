==================================================
1. PRODUCT VISION
==================================================

ClassBridge is an AI-powered personal learning companion.

The goal is NOT simply:

“Upload a PDF and chat with AI.”

That already exists in tools such as ChatGPT and other AI assistants.

ClassBridge's differentiation is the complete learning loop:

DIAGNOSE → TEACH → PRACTICE → MEASURE → ADAPT → RETEST

The application should take a student's course material and turn it into a personalized learning system.

A student should be able to:

1. Upload course material.
2. Extract and process the material.
3. Identify important topics/concepts.
4. Take a short diagnostic test.
5. Establish baseline knowledge.
6. Learn concepts using an AI teacher grounded in the uploaded material.
7. Ask doubts.
8. Practice with AI-generated questions.
9. Track performance at concept/topic level.
10. Detect weak concepts.
11. Receive personalized revision recommendations.
12. Retest weak concepts.
13. See improvement from baseline to current mastery.

Example:

Before:
Functional Dependencies — 40%

After targeted learning:
Functional Dependencies — 82%

The application should make this improvement visually obvious.

17. RAG ARCHITECTURE
==================================================

Implement a real RAG architecture where possible.

Pipeline:

PDF
 ↓
Text extraction
 ↓
Cleaning
 ↓
Chunking
 ↓
Embeddings
 ↓
Vector storage/search
 ↓
Retrieve relevant chunks
 ↓
Send context to LLM
 ↓
Generate grounded answer

Use PyMuPDF for PDF extraction.

For vector search, use a lightweight local solution that works reliably in Replit.

Prefer a simple implementation such as:

FAISS

or another lightweight vector index.

If FAISS creates environment/deployment problems, implement a reliable fallback using embeddings plus cosine similarity with NumPy.

Do NOT make the entire application dependent on an unnecessarily complicated vector database.
